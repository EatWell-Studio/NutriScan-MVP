# ADR 0017: Code ownership

- Status: Accepted
- Date: 2026-09-26
- Decision: D18

## Decision

The code in this repository is jointly owned by the two members of EatWell Studio (GitHub `hannesgao` and `hyhcrh`).

## Consequences

- Changing the license or granting rights to third parties requires the agreement of both members.
- The existing `LICENSE` file (initial commit) names "EatWell Studio" as copyright holder. When D16 (code license and contribution terms) is decided, the copyright line is updated to match this ownership.
- Contributions from anyone outside the two members fall under the contribution terms chosen in D16. DCO does not grant relicensing rights; a CLA can. See [DEV_PLAN §7.3](../DEV_PLAN.en.md).
- This is not legal advice. If EatWell Studio becomes a legal entity, revisit this ADR.
